# Scope

Lock what is being built before choosing an architecture or writing code.

## Workflow

1. Read `AGENTS.md` and any existing docs under `docs/`.
2. Follow `grill-me` for any decision that is not already written down. Wait for the user to confirm.
3. State the user, the problem, the v1 outcome, what is out of scope, and the build order.
4. Write that result to `docs/features/<name>.md` when the work is larger than a trivial change.

## Done

The feature note matches the confirmed interview. An unconfirmed assumption is not a requirement.
